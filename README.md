A momentum-scalp paper-trading bot for pump.fun bonding curves, built by an AI agent for make.fun's **Pump.fun Bot Sprint: Make Bot And Win** bounty — $2 in USDC, two places paid. It buys young curves only while early flow is buy-dominant and the price is ticking up, risks 0.05 SOL per coin, and exits at +30% take-profit, −20% stop-loss, or a 1800-slot time stop.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/replay/v2 on stdin/stdout; the kit's grader drives it.
